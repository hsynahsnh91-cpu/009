# منصة مَدار سوريا (Madar Syria) — إدارة المهام والمشاريع والدفع الإلكتروني

تطبيق ويب متكامل باللغة العربية (RTL) لإدارة المهام والمشاريع والفرق في المحافظات السورية مع بوابة دفع إلكتروني سورية موحدة ومحفظة رقمية، مصمم وفق معايير **UI/UX Pro Max**.

---

## طريقة التشغيل على جهازك (Local Setup)

### المتطلبات:
- تثبيت **Node.js** (الإصدار 18 أو أحدث) — لا يتطلب أي مكتبات خارجية معقدة.

### خطوات التشغيل:
```bash
cd app
npm start
```
ثم افتح المتصفح على الرابط:
```
http://localhost:3000
```

---

## هيكل ملفات التطبيق (`app/`)
- `server.mjs` — الخادم الخلفي (Node.js HTTP/REST API) مع قاعدة البيانات المحلية التلقائية.
- `data/db.json` — ملف حفظ البيانات الدائم (المهام، المشاريع، المحفظة، المعاملات، الإعدادات).
- `public/index.html` — الهيكل الرئيسي للواجهة الأمامية المتجاوبة (RTL) ونوافذ المهام والإيصالات.
- `public/styles.css` — نظام التصميم والألوان الدمشقية والوضع الليلي والنهاري وتنسيقات الطباعة.
- `public/app.js` — منطق الواجهة التفاعلية، لوحة كانبان، بوابة الدفع السورية، والمخططات التحليلية.
